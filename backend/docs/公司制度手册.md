# 智链科技公司制度手册

## 第一章 考勤制度

### 工作时间
公司实行标准工时制，工作时间为周一至周五，上午9:00至下午18:00，午休时间为12:00至13:30。

### 打卡规定
1. 员工应在上班前和下班后通过钉钉打卡
2. 迟到15分钟以内扣50元，15-30分钟扣100元
3. 每月允许2次10分钟以内的弹性迟到
4. 早退参照迟到标准处理

### 请假制度
- 事假需提前1天申请，扣除当日工资
- 病假需提供医院证明，发放80%工资
- 年假按工龄计算：1-5年5天，5-10年10天，10年以上15天

## 第二章 薪酬福利

### 薪资结构
月薪 = 基本工资 + 岗位工资 + 绩效奖金 + 各类补贴

### 发薪日
每月15日发放上月工资，遇节假日提前。

### 五险一金
公司按国家规定为员工缴纳养老保险、医疗保险、失业保险、工伤保险、生育保险和住房公积金。

### 福利
- 下午茶：每周三、周五下午15:30提供
- 团建：每季度一次部门团建
- 体检：每年一次免费体检
- 节日礼金：春节、中秋等节日发放礼金或礼品

## 第三章 AI大模型开发岗位要求

### 岗位职责
1. 负责大模型微调、RAG系统、AI Agent的设计与开发
2. 参与NLP/CV算法研究与工程落地
3. 优化模型推理性能，降低部署成本
4. 编写技术文档，参与代码评审

### 技术要求
- 熟练掌握Python，熟悉PyTorch深度学习框架
- 了解Transformer架构，有LoRA/QLoRA微调经验优先
- 熟悉LangChain、LlamaIndex等Agent框架
- 熟悉向量数据库（FAISS、Chroma、Milvus）
- 有FastAPI、Docker部署经验

### 晋升通道
初级工程师 → 中级工程师 → 高级工程师 → 技术专家 → 技术总监

## 第四章 项目管理规范

### 开发流程
1. 需求评审 → 技术方案设计 → 编码 → 代码评审 → 测试 → 上线
2. 所有代码必须经过Code Review才能合并
3. 提交信息格式：type(模块): 描述

### 项目命名规范
- 项目代号采用"项目X_主题"格式
- Git分支：main（生产）、develop（开发）、feature/xxx（功能）、hotfix/xxx（修复）
